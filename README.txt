Organizador de Arquivos

Projeto desenvolvido em Python para organizar automaticamente arquivos em diretórios de acordo com suas extensões.

Funcionalidades:

.Identificação automática das extensões dos arquivos.

.Separação de arquivos por categorias.

.Criação automática de diretórios.

.Prevenção de conflitos entre arquivos com nomes iguais.

.Organização de arquivos encontrados em subpastas de primeiro nível.

Tecnologias utilizadas:

 .Python

 .pathlib

Como executar:

.Tenha o Python instalado.

.Baixe ou clone este repositório.

.Execute o arquivo principal:

.python main.py

.Informe o caminho da pasta que deseja organizar.
